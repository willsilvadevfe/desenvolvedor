Etapa 1 — Planejamento e estrutura inicial


•	Quais informações serão armazenadas? Produto, descrição e valor.
•	Qual banco será utilizado? PostgreSQL.
•	Quais operações serão necessárias? Criar, listar, editar e excluir.
•	Qual será o frontend? HTML, CSS e JavaScript.
•	Qual será o backend? Node.js com Express e Sequelize.

Etapa 2 — Criar o projeto e instalar as dependências

usando npm para instalar as dependências

express - Criar o servidor e as rotas HTTP
sequelize -	ORM que conecta o código JavaScript ao banco
pg - Driver de comunicação com PostgreSQL
pg-hstore -	Suporte utilizado pelo Sequelize em operações específicas com PostgreSQL
nodemon - Reiniciar o servidor automaticamente durante o desenvolvimento
